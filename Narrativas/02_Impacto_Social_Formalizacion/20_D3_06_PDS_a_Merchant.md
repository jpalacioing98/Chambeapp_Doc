# Narrativa: De Obrero a Empresario — PDS → Merchant

**KPI Asociado:** D3.6  
**Nivel:** 🔴 Crítico (anual) / 🟠 Táctico (trimestral)  
**Dimensión:** 3. Transición a Empleo Formal y Formalización

---

## La Historia

La **transición PDS → Merchant (negocio propio)** es **el sueño de movilidad ascendente**. Un PDS que formaliza, ahorra, compra herramientas, contrata ayudantes, **se vuelve generador de empleo formal**. Este KPI mide: **% PDS que registran `negocio` + KYC Merchant aprobado**.

---

## Qué Nos Dice Realmente

| % PDS → Merchant/Año | Interpretación | Acción Inmediata |
|----------------------|----------------|------------------|
| **< 2%** | Techo de cristal: PDS no escalan, falta capital, habilidades gerenciales, red clientes | "Merchant Starter Pack" (herramientas + publicidad + asesoría legal) + mentor PDS Experto |
| **2–5%** | Emergente: algunos PDS top (Experto, N5) dan el salto, compran herramientas, contratan 1-2 ayudantes | Mentoría N5→Merchant + financiamiento herramientas + publicidad gratis 3 meses |
| **> 5%** | **Ecosistema emprendedor**: plataforma genera empleadores, no solo trabajadores | Escalar: "PDS a Merchant Academy" + financiamiento herramientas + red mentores |

---

## Ruta Natural: PDS Experto → Merchant

**PDS Experto (N5)** + **≥70 contratos** + **Certificación SENA** + **TrustScore 0.9+** + **Ahorro monedas/COP** 
→ **Compra "Merchant Starter Pack"** (herramientas + publicidad + asesoría legal) 
→ **Registra negocio** (KYC Merchant) 
→ **Publica anuncios "contrato"** (0 monedas) 
→ **Contrata PDS N1-N2** (marañas → contratos) 
→ **Ciclo virtuoso: PDS formalizado genera empleo formal**

---

## Palancas de Intervención

1. **"Merchant Starter Pack"** (costo ~$500k COP): Kit herramientas básicas + 3 meses publicidad gratis + Asesoría legal registro + 500 monedas bono
2. **Mentoría N5→Merchant:** PDS Experto (N5) mentoriza PDS N4 que quiere escalar → 500 monedas/mentoría
2. **Financiamiento herramientas:** Alianza entidad financiera / caja compensación → crédito herramientas (pago con monedas ganadas)
2. **Publicidad gratis 3 meses:** Anuncios "contrato" ilimitados gratis primer trimestre
2. **Asesoría legal registro:** Alianza cámaras de comercio / cámaras de comercio → registro gratis + RUT + cámara


---

## Riesgo Si Se Ignora

- **PDS → Merchant < 1%/año por 3+ años** → Techo de cristal confirmado → PDS top se van a competencia / crean negocio offline sin trazabilidad → plataforma pierde a sus mejores usuarios
- **Sin financiamiento herramientas** → PDS N5 no pueden dar salto → "Tengo la habilidad pero no el capital" → frustración → churn
- **Sin mentoría** → PDS cometen errores gerenciales (legales, financieros, tributarios) → negocio fracasa → desconfianza ecosistema
