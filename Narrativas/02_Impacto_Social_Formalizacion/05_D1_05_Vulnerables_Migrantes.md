# Narrativa: Inclusión de Vulnerables — Migrantes y Poblaciones Especiales

**KPI Asociado:** D1.7  
**Nivel:** 🔴 Crítico (mensual) / 🟠 Táctico (semanal)  
**Dimensión:** 1. Distribución de Roles y Equidad de Acceso

---

## La Historia

Valledupar recibe **migración venezolana y desplazados internos**. Sin cédula colombiana, **no existe KYC estándar**. Si ChambeApp no tiene ruta alternativa (pasaporte, PEP, salvoconducto + validación biométrica), **condena a la informalidad total** a quienes más necesitan formalización.

---

## Qué Nos Dice Realmente

| KYC Vulnerables | Interpretación | Acción Inmediata |
|-------------------|----------------|------------------|
| **< 30%** | Documentación incompatible, verificadores sin entrenamiento, UX solo para colombianos | Catálogo docs alternativos (PEP, pasaporte+PEP, salvoconducto) + validador biométrico + verificador dedicado |
| **30–50%** | Ruta alternativa funcional pero lenta (revisión manual caso a caso) | Verificador dedicado + API validación biométrica + docs alternativos en UX |
| **> 50%** | **Inclusión real**: docs alternativos válidos, verificadores especializados, alertas Ley 1429 aplican igual | Escalar: alianza ACNUR/OIM + caso video migrante formalizado |

---

## Riesgo Legal

Si rechazamos migrantes por docs, **violamos principios de no discriminación** y perdemos talento (muchos son oficios escasos: soldadura TIG, electricidad industrial, soldadura SMAW).

---

## Palancas de Intervención

1. **Catálogo docs alternativos:** PEP (Permiso Especial Permanencia), Pasaporte + PEP, Salvoconducto, Cédula Extranjería
2. **Validador biométrico facial:** Liveness detection + OCR pasaporte/PEP + hash en blockchain (opcional)
3. **Verificador dedicado migración:** Entrenado en docs internacionales + sensibilizado + bilingüe (español/portugués básico)
4. **Alianza ACNUR/OIM:** Referidos bidireccionales + capacitación verificadores + funding certificación SENA
5. **UX inclusiva:** Selector "Tipo documento" → muestra requisitos específicos por tipo + guía visual

---

## Riesgo Si Se Ignora

- **KYC Vulnerables < 20%** → Exclusión sistemática → riesgo legal (Ley 1429 Art. 3 no discriminación) + pérdida talento escaso
- **Verificadores sin entrenamiento** → Rechazan docs válidos por ignorancia → denuncia Superintendencia / Defensoría
- **Oficios escasos perdidos** → Soldadores TIG, electricistas industriales venezolanos → se van a competencia informal
