# Flujo de Trabajo para Agentes de UI/UX

## Pasos del Proceso y Skills Recomendadas

1. **Instalación de Skills de UX:** Utiliza `webdesignguidelines` de Vercel (Alternativa: `frontenddesign` de Anthropic).
2. **Definición de Specs y Reglas:** Emplea `shadcnui` para codificar el sistema de diseño (Alternativa: `vercelreactbestpractices`).
3. **Generación de Mockups:** Crea wireframes mediante prompts directos sobre la estructura y el layout.
4. **Aplicación de Variables Semánticas:** El agente debe implementar tokens de diseño basados en el archivo central.
5. **Escritura de Tests:** Usa `skillcreator` para generar especificaciones de pruebas (Alternativa: `skill-creator`).
6. **Implementación y Crítica:** Ejecuta `designcritique` para una auditoría scored del resultado final (Alternativa: `agent-browser-verify`).
